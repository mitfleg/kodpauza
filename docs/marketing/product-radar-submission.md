## Описание

Kodpauza — бесплатное расширение для VS Code, Cursor и VSCodium. Оно показывает
короткую нативную рекламную строку только во время активного ожидания ответа
Codex или Claude Code. После завершения ответа объявление исчезает.

Разработчик получает 50% стоимости каждого подтвержденного чистого показа.
Показ засчитывается только после пяти секунд непрерывной видимости в активном
окне редактора.

Расширение не читает и не передает исходный код, содержимое файлов и терминала,
промпты или ответы AI. Интеграция проверяет совместимость версии инструмента и
отключается безопасно, если новую сборку нельзя подтвердить.

Сейчас Kodpauza ищет первых активных пользователей, которые регулярно работают
с Codex или Claude Code и готовы проверить расширение в обычном рабочем процессе.

## Какую проблему решает продукт

Во время больших задач AI-инструменту требуется время на анализ проекта,
выполнение команд и подготовку ответа. Kodpauza превращает эту естественную
паузу в дополнительный доход, не создавая отдельную рекламную панель и не меняя
сценарий работы разработчика.

## Чем отличается

- реклама появляется только во время реальной работы AI;
- подтверждение требует пяти секунд видимости;
- 50% стоимости чистого показа начисляется разработчику;
- нет доступа к коду, файлам, промптам и ответам;
- поддерживаются Codex и Claude Code в VS Code-совместимых редакторах;
- совместимость патча проверяется до установки, предусмотрен безопасный откат.

## Что нужно от сообщества

Ищем 20 разработчиков для семидневного теста в обычной работе. Нужны замечания
по установке, совместимости с версиями Codex и Claude Code, понятности объявления
и статистике начислений. Искусственно создавать ожидания или показы не нужно.
