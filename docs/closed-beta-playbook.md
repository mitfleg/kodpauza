# Закрытая бета Kodpauza

Цель первого набора — проверить не количество регистраций, а полный путь разработчика до первого оплаченного показа без ручного вмешательства команды.

## Кого приглашаем

- 10–20 разработчиков, которые ежедневно используют Codex или Claude Code в VS Code/Cursor;
- 2–3 рекламодателя с реальными HTTPS-ссылками;
- минимум macOS, Windows и Linux среди разработчиков;
- по возможности разные провайдеры интернета, офисные сети и VPN.

## Сообщение разработчику

> Kodpauza показывает короткое рекламное сообщение только во время ожидания ответа Codex или Claude Code. Расширение не читает код, промпты и ответы AI. Для закрытой беты зарегистрируйтесь как разработчик, подтвердите почту, установите расширение из Marketplace и подключите найденные AI-инструменты. После первого подтверждённого показа начисление появится в кабинете.

Ссылки:

- регистрация: https://kodpauza.ru/register
- установка: https://kodpauza.ru/install
- инструкция: https://kodpauza.ru/docs
- поддержка: https://kodpauza.ru/support и Telegram `@mitfleg`

## Сценарий участника

1. Зарегистрироваться как разработчик и подтвердить почту кодом.
2. Установить Kodpauza из Marketplace, чтобы последующие версии обновлялись автоматически.
3. Выполнить `Kodpauza: Войти`.
4. Выполнить `Kodpauza: Подключить интеграции` и перезапустить окно редактора.
5. Отправить обычный рабочий запрос в Codex или Claude Code.
6. Оставить окно активным минимум на пять секунд во время показа.
7. Открыть кабинет и проверить появление события и начисления.
8. Сообщить организатору только шаг, на котором возникла проблема, ОС, редактор и версии расширений. Не присылать код проекта, промпты, токены и пароли.
9. Для ручной выплаты создать заявку в кабинете, затем передать `@mitfleg` email аккаунта, имя, банк и телефон СБП.

## Что ежедневно проверяет администратор

- конверсию каждого шага на главной странице админки;
- неподдерживаемые версии Codex/Claude в разделе «Безопасность»;
- сигналы антифрода и ошибки ЮKassa;
- состояние API, диска и offsite backup по Telegram-уведомлениям;
- пользователей, которые вошли из расширения, но не подключили интеграции;
- пользователей с рекламной выдачей без подтверждённого показа.

## Критерии завершения беты

- не менее 70% подтвердивших почту вошли из расширения;
- не менее 70% вошедших подключили хотя бы один AI-инструмент;
- не менее 80% подключивших получили подтверждённый показ;
- нет потери финансовых проводок и повторного списания;
- backup ежедневно загружается в S3 и проходит автоматическое восстановление;
- новая неподдерживаемая версия AI-инструмента попадает в Telegram и админку.

## Что не обещаем участникам

- фиксированный доход;
- автоматическую выплату без ручной проверки;
- поддержку неизвестной версии Codex/Claude до выпуска проверенного патча;
- оплату подозрительных, слишком коротких или параллельных показов с одного IP.
