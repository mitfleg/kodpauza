# ERID и Яндекс ОРД

Kodpauza хранит юридическое имя и ИНН рекламодателя отдельно от публичного бренда. В расширение
передаётся только публичный бренд. Каждый активный креатив имеет собственный `CampaignCreative.erid`;
`Campaign.erid` сохраняется как совместимый резерв для старых версий API и расширения.

Администратор не может активировать кампанию, если не заполнены юридические данные, публичная
HTTPS-страница рекламодателя или ERID хотя бы одного активного креатива.

## Привязка собственной рекламы

После регистрации организации, площадки и креативов в кабинете ОРД администратор вызывает
`PATCH /v1/admin/campaigns/:id/ord` и передаёт:

- локальный ID организации в ОРД;
- локальный ID площадки в ОРД;
- для каждого активного креатива его ID объекта в ОРД и полученный ERID.

Токены не хранятся в исходниках или `.env`: ERID сохраняется в базе у конкретного креатива.
OAuth-токен API ОРД является серверным секретом
`KODPAUZA_YANDEX_ORD_API_TOKEN`.

## Ежемесячная статистика саморекламы

API считает только подтверждённые показы из `AdServe.impressionRecordedAt`, создаёт отдельный отчёт
на каждый креатив и площадку и отправляет в `/api/v8/statistics` нулевую стоимость саморекламы.
Повторная подготовка месяца идемпотентна. Принятые отчёты не пересчитываются.

Сервис каждые шесть часов:

1. проверяет статусы ранее отправленных запросов;
2. готовит отчёты за предыдущий календарный месяц;
3. отправляет черновики и повторяет отклонённые запросы.

Без OAuth-токена автоматическая отправка выключена. Для ручного контроля доступны:

- `GET /v1/admin/ord/reports`;
- `POST /v1/admin/ord/reports/prepare`;
- `POST /v1/admin/ord/reports/:id/submit`;
- `POST /v1/admin/ord/reports/:id/refresh`.
