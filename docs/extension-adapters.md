# Интеграция расширения

Рабочая реализация находится в `packages/vscode-extension/src`.

## Подключение

После успешного входа Kodpauza автоматически подключает все найденные совместимые инструменты:

- Codex с ID `openai.chatgpt`;
- Claude Code с ID `anthropic.claude-code`;
- lifecycle hooks `UserPromptSubmit` и `Stop`;
- UI-патч для точного хэша либо единственного доказанного структурного совпадения;
- полные резервные копии в `~/.kodpauza/backups`;
- защищенный bridge только на `127.0.0.1`.

Codex hooks хранятся в `~/.codex/hooks.json`, Claude Code hooks - в `~/.claude/settings.json`. Установщик сохраняет чужие обработчики и удаляет только записи Kodpauza. После обновления инструмента расширение автоматически проверяет новую версию, переносит патч и перезапускает окно. Повторный вход и повторное подключение не нужны. Ручная команда подключения остается для восстановления. Команда отключения запрещает последующее автоподключение, пока пользователь явно не подключит интеграции снова.

Если Codex сообщает о недоверенных hooks, пользователь запускает `codex` в терминале, выполняет `/hooks` в Codex CLI и явно доверяет обработчикам. Боковая панель Codex эту CLI-команду не обрабатывает. Обход hook trust не используется.

## Жизненный цикл показа

1. `UserPromptSubmit` отправляет локальное событие `start`.
2. Расширение запрашивает объявление для `codex_vscode` или `claude_code_vscode`.
3. Codex показывает рекламу вместо активных строк ожидания; Claude Code - вместо текущего spinner-глагола. История, `Compacting`, разрешения и завершенные статусы не меняются.
4. Каждый DOM-экземпляр рекламы получает отдельный `viewId` и сообщает `visible/hidden` локальному bridge.
5. Показ учитывается после пяти непрерывных секунд только если элемент подключен к DOM, виден минимум на 80%, не скрыт атрибутами или стилями, находится внутри viewport и не перекрыт в центральной точке.
6. Скрытие окна, сворачивание reasoning-блока, прокрутка, перекрытие или потеря heartbeat немедленно сбрасывают непрерывный таймер.
7. В каждом окне редактора работает свой экземпляр расширения, но фиксированным UI bridge владеет только окно с фокусом. При переключении старый экземпляр очищает видимость и освобождает порт, новый занимает его автоматически; время между окнами не суммируется.
8. `Stop` отправляет локальное событие `stop`, после чего объявление скрывается.

Несколько параллельных запросов учитываются независимыми счетчиками для Codex и Claude Code. Защитный таймер убирает зависший показ через два часа.

## Приватность и совместимость

Hook-команды получают stdin протокола инструмента, но скрипт не преобразует его в строку и не разбирает JSON. В bridge передаются только тип события и локальный `cwd`; в рекламный API `cwd` не передается.

- новая версия автоматически патчится только при точном хэше или полном dry-run существующего профиля;
- неоднозначная, неполная или синтаксически некорректная структура работает fail-closed без рекламы;
- восстановление проверяет резервную копию и не пишет за пределы каталога расширения;
- поврежденные `hooks.json` и `settings.json` не перезаписываются;
- проверенные Claude Code версии: `2.1.207`, `2.1.209`, `2.1.212`, `2.1.214`, `2.1.238`;
- отдельного демонстрационного адаптера нет: показы идут только через реальные интеграции Codex и Claude Code.
