# Kodpauza — зарабатывайте, пока AI работает

Вы уже ждете, пока Codex или Claude Code анализирует проект и выполняет запрос. Kodpauza превращает это время в дополнительный доход: расширение показывает короткое объявление в активном статусе AI-помощника и начисляет вознаграждение за подтвержденный просмотр.

[Установить](https://kodpauza.ru/install) · [Для разработчиков](https://kodpauza.ru/for-developers) · [Условия начислений](https://kodpauza.ru/docs#delivery-rules) · [Поддержка](https://kodpauza.ru/support) · [Политика конфиденциальности](https://kodpauza.ru/privacy)

![Рекламная строка Kodpauza во время ожидания ответа AI](https://kodpauza.ru/images/kodpauza-ad-preview.png)

Объявление появляется внутри естественной паузы AI и исчезает после завершения ответа. Внешний вид Codex и Claude Code остается прежним: без дополнительных таймеров, подписей и рекламных панелей.

## Как начать зарабатывать

1. Установите Kodpauza в VS Code или Cursor.
2. Зарегистрируйтесь как разработчик на [kodpauza.ru](https://kodpauza.ru).
3. Откройте палитру команд: нажмите `Ctrl + Shift + P` в Windows/Linux или `Cmd + Shift + P` на macOS.
4. В появившейся строке вверху окна введите `Kodpauza: Войти`, выберите эту команду в списке и нажмите `Enter`.
5. Сначала введите почту аккаунта Kodpauza, затем пароль. Поля ввода появятся вверху окна редактора.
6. Kodpauza автоматически подключит найденные совместимые интеграции и при необходимости один раз перезапустит окно.
7. Продолжайте работать с Codex и Claude Code как обычно.

Команда `Kodpauza: Подключить интеграции` нужна только для ручного восстановления. Повторно входить и подключать интеграции после перезапуска не нужно. Kodpauza сохраняет защищенную сессию устройства и автоматически восстанавливает совместимую интеграцию после обновления AI-инструмента.

## За что начисляются деньги

- объявление должно быть непрерывно видно не менее пяти секунд;
- окно редактора должно оставаться активным;
- если открыто несколько окон редактора, начисление идет только в окне с фокусом; при переключении незавершенный пятитисекундный интервал начинается заново;
- не менее 80% рекламной строки должно находиться в видимой области;
- скрытый или свернутый блок рассуждений не считается просмотром;
- один рекламный объект оплачивается только один раз;
- подозрительные и слишком частые события не оплачиваются.

Баланс и история начислений доступны в кабинете разработчика. Полные лимиты и правила всегда опубликованы на [странице условий](https://kodpauza.ru/docs#delivery-rules).

## Приватность

Kodpauza не отправляет рекламной платформе текст запросов, ответы AI, исходный код или содержимое файлов. Локальный bridge принимает только событие начала или завершения работы и путь рабочей папки; в API уходят только идентификаторы рекламного события, версия инструмента и доказательство видимости.

Access token, сессия устройства и ключ подписи хранятся в VS Code `SecretStorage`. Неуспешные события остаются в локальной очереди и повторно отправляются с тем же `eventId`, поэтому временная ошибка сети не создает двойное начисление.

## English summary

Kodpauza is a free extension for developers who use Codex or Claude Code in VS Code, Cursor, or VSCodium. It displays a short native ad only while the AI is working and credits 50% of each verified impression to the developer. Kodpauza does not read or transmit source code, files, terminal contents, prompts, or AI responses.

## Безопасность интеграции

Kodpauza применяет версионный UI-патч только после структурной и синтаксической проверки файлов Codex или Claude Code. Перед изменением создается резервная копия. Если совместимость новой версии нельзя доказать, реклама отключается, оригинальный интерфейс продолжает работать, а версия отправляется в центр совместимости Kodpauza.

Точно проверенные профили Codex: `26.623.141536`, `26.707.71524`, `26.707.91948`, `26.715.31925`, `26.721.30844`, `26.721.41059`, `26.727.40816`, `26.5727.51351` и `26.803.41515`; Claude Code: `2.1.207`, `2.1.209`, `2.1.212` и `2.1.214`.

- `Kodpauza: Включить рекламу` и `Kodpauza: Выключить рекламу`;
- `Kodpauza: Показать баланс`;
- `Kodpauza: Открыть кабинет`;
- `Kodpauza: Запустить диагностику`;
- `Kodpauza: Восстановить настройки`.
