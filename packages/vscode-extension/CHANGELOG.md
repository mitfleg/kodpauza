# История версий

## 0.7.29

- Добавлен точный обратимый UI-патч для Codex `26.803.41515`.
- Поддержаны два descriptor-placeholder, новый CSP-якорь и обновлённый модуль `thinking-shimmer`.
- При неподдерживаемой версии пользователь получает понятную инструкцию обновить AI-инструмент и Kodpauza, а затем переподключить интеграции.

## 0.7.28

- Добавлен точный обратимый UI-патч для Codex `26.5727.51351`.
- Подтверждены новые SHA-256 host, `local-conversation-turn` и `thinking-shimmer`, а также изменённый CSP-якорь.
- Неизвестные или изменённые сборки по-прежнему отклоняются в fail-closed режиме.

## 0.7.27

- Добавлен точный обратимый UI-патч для Codex `26.727.40816`.
- Поддержана новая descriptor-only структура и вернувшийся отдельный `thinking-shimmer`.
- Неизвестные или изменённые сборки по-прежнему отклоняются в fail-closed режиме.

## 0.7.26

- Карточка расширения стала понятнее для пользователей Codex, Claude Code, VS Code и Cursor.
- Добавлены поисковые ключевые слова, категория AI-инструментов и ссылки на официальный сайт и поддержку.
- В описание добавлен реальный пример рекламной строки и краткое англоязычное пояснение.

## 0.7.25

- Добавлена маркировка собственных рекламных переходов через ERID кампании.
- Ссылки сохраняют существующие query-параметры и fragment.
- Клиент разрешает открывать только безопасные HTTP/HTTPS-ссылки.
