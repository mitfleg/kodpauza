# История версий

## 0.7.26

- Карточка расширения стала понятнее для пользователей Codex, Claude Code, VS Code и Cursor.
- Добавлены поисковые ключевые слова, категория AI-инструментов и ссылки на официальный сайт и поддержку.
- В описание добавлен реальный пример рекламной строки и краткое англоязычное пояснение.

## 0.7.25

- Добавлена маркировка собственных рекламных переходов через ERID кампании.
- Ссылки сохраняют существующие query-параметры и fragment.
- Клиент разрешает открывать только безопасные HTTP/HTTPS-ссылки.
